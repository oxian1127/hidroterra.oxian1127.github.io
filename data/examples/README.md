# Datos de Ejemplo — Montes de María

Este directorio contiene conjuntos de datos de prueba diseñados para la verificación técnica, demostración y capacitación de promotores comunitarios en la subregión de Montes de María (departamentos de Bolívar y Sucre, Colombia).

## Principios de los datos de ejemplo

1. **No se cargan automáticamente:** La aplicación inicia con la base de datos limpia. El usuario decide voluntariamente si desea importar este conjunto desde el módulo **Respaldo y Datos**.
2. **Sin datos personales sensibles:** Los nombres y contactos son ficticios o institucionales de referencia comunitaria.
3. **Georreferenciación contextual:** Las coordenadas corresponden a la ubicación geográfica real de municipios y áreas veredales de Montes de María (El Carmen de Bolívar, San Jacinto, San Juan Nepomuceno, Ovejas y Chalán).
4. **Coherencia hídrica:** Las precipitaciones simuladas representan un régimen de lluvias tropical bimodal característico de la subregión caribeña colombiana.
